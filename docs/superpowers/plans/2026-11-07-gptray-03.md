> Execute inline with executing-plans, test-driven-development and verification-before-completion. The user's explicit autonomous instruction supplies execution authorization; do not ask design/implementation questions already settled by the brief.

**Goal:** Safely lower inactive WebView2 memory, fix initial Full layout and add an independent Full hotkey, with one coherent tested Windows delivery.
**Spec:** GPTray 0.3 assignment of 2026-11-07; baseline main 6cf978e1efdb55d6195571c54fc8a6c437a52a1f.
**Architecture:** Keep one lazy WebView, existing profile, destructive opt-in timer and manual discard. Use official Low/Normal memory target exclusively, without suspend, on UI-thread access through Tauri's with_webview. Construct the requested native mode before WebView initialization; synchronize native WebView client bounds before showing. Test pure policy and attempt a native WebView2 smoke probe on CI with isolated disposable an isolated blank document, never the personal profile.
**Tech stack:** Locked Tauri 2.11.5, Wry 0.55.1, webview2-com 0.38.2, Windows 0.61.3. Two Windows-only direct dependency declarations reuse existing locked packages for typed native APIs. The subsequent RustSec check justifies the narrow plist/quick-xml security update and its base64 dependency (SECURITY-REVIEW.md).

## Discovery and decisions

Graphify graph_stats confirms exact baseline: 141 nodes, 225 edges; query_graph, rank_files and impact_and_risk identify lib.rs, lifecycle.rs and geometry.rs. tests_for returns no links for lib.rs/lifecycle.rs despite 15 real source tests: graph test coverage is incomplete and is not execution evidence. Direct source agrees that get_or_create_panel always constructs Quick, then open mutates dimensions; Wry's resize notification is asynchronous. Wry supports memory targets but Tauri's PlatformWebview does not expose the Wry setter. Its public controller + typed ICoreWebView2_19 is the supported access path. QueryInterface is mandatory for older installed runtimes.

Microsoft ICoreWebView2_19: Low preserves scripts/network, Normal must be restored explicitly. Introduced WebView2 SDK 1.0.1823.32 / Runtime 114.0.1823.32. TrySuspend (_3, SDK 1.0.774.44) requires invisible controller and pauses scripts/timers; it is not appropriate by default when generation status is unknowable. Do not combine strategies. Active Low, forced GC, cache clearing, browser flags and automatic refresh are rejected: no measured benefit or preservation guarantee. Normal remains the active target; inactive Full/minimized/hidden may request Low.

## Global constraints

- Single branch feat/gptray-0.3; no changes to main, no merge or release.
- Same identifier, profile and real chatgpt.com; no user-data clearing, telemetry, website DOM/injected scripts.
- Destructive discard remains manual or warned opt-in off at each startup.
- Preserve epochs, pending reopen, one window label, autostart, saved bounds.
- No claimed RAM saving without equivalent process-group measurements.
